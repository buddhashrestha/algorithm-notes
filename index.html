Binary Search

Find a monotonic boundary. Save a valid midpoint, then move toward the first or last valid index.

Framework Rules Rotated arrays Solutions

Boundary framework

The reusable setup stays the same.

Fixed setup

TTTFFF 
if valid(m):

else:
    r = m - 1

LAST -> save -> go RIGHT

Final rule

First valid: save m, search left. Last valid: save m, search right.

Before using the template

The predicate must be fixed and monotonic.

  • 1
    Fixed

    valid(i) keeps the same meaning while l and r move.

  • 2
    Monotonic

    Its results have exactly one boundary: F...T or T...F.

The operator does not decide FIRST or LAST

The boolean shape decides it.

PredicateExampleResult
nums[i] >= target [1,3,5,7,9] -> F F F T Ttarget = 7 First validFirst True: index 3, value 7. Save and go left.
nums[i] <= target [1,3,5,7,9] -> T T T F Ftarget = 5 Last validLast True: index 2, value 5. Save and go right.
nums[i] <= nums[r] The value of r moves during search. Not fixed
Exact target

The boundary gives a candidate. Verify: ans != -1 and nums[ans] == target.

Rotated sorted arrays

Find the pivot, select one sorted side, then run boundary search.

Distinct values

Freeze last = nums[-1]. The first nums[i] <= last is the pivot.

[4,5,6,7,0,1,2] -> F F F F T T T

FIRST valid -> pivot

Duplicate values

Leading copies of last create an unwanted True prefix.

T T F F T T T -> skip prefix -> F F T T T

Check target == last -> skip leading last values

Complexity with unrestricted duplicates

Usually O(log n), but worst case O(n). Equal values can hide the pivot, so the linear worst case is unavoidable.

class Solution:
    def search(self, nums: List[int], target: int) -> bool:
        end = len(nums) - 1
        last = nums[end]

        if target == last:
            return True

        start = 0
        while start < end and nums[start] == last:
            start += 1

        l, r = start, end
        pivot = -1
        while l <= r:
            m = l + (r - l) // 2
            if nums[m] <= last:
                pivot = m
                r = m - 1
            else:
                l = m + 1

        if target < last:
            l, r = pivot, end
        else:
            l, r = start, pivot - 1

        ans = -1
        while l <= r:
            m = l + (r - l) // 2
            if nums[m] <= target:
                ans = m
                l = m + 1
            else:
                r = m - 1

        return ans != -1 and nums[ans] == target

Algorithm 02

Backtracking

Build one candidate step by step. Explore each valid choice, then undo it so the next branch starts clean.

How to think Framework Visualize Decisions Problem map Solutions

How to think inside dfs

Focus on one call, not the entire recursion tree.

dfs(state, path)

path is what you have built. state tells you where you are and which choices remain.

  • 1
    Stop

    If path is complete, save path.copy() and return.

  • 2
    Choose and explore

    Add one valid choice, update state, and recurse.

  • 3
    Undo

    Remove the choice so the next branch starts from the same path.

Concrete example

dfs(1, [1]) means: "I chose 1. Now decide whether to take or skip nums[1]."

One framework

Each problem changes the state, choices, completion rule, and pruning rule.

Universal backtracking template
res = []

def backtrack(state, path):
    if complete(state, path):
        res.append(path.copy())
        return

    for choice in choices(state, path):
        if not valid(choice, state, path):
            continue

        path.append(choice)                    # choose
        next_state = apply(choice, state)

        backtrack(next_state, path)             # explore

        undo(choice, state)                    # if state is mutable
        path.pop()                             # undo path

backtrack(initial_state, [])
return res
ChooseAdd one decision to path.
ExploreRecurse with new state.
UndoRestore state and path.
Why copy path?

The same mutable list is reused. Without path.copy(), later pops would change saved answers.

See the recursion tree

Subsets of [1, 2]: each edge is a choice and each leaf is one answer.

DFS explores take, returns and undoes it, then explores skip.

Pick the decision shape

Most problems use take/skip or choose-from-many.

Take / skip

At index i, decide whether the current value belongs in the answer.

path.append(nums[i])
dfs(next_i, path)    # take
path.pop()

dfs(skip_i, path)    # skip

Choose from many

At each answer position, try every currently available option.

for i in range(len(nums)):
    if used[i]:
        continue
    path.append(nums[i])
    used[i] = True
    dfs(path)
    used[i] = False
    path.pop()

PermutationsChoose any unused value

Each answer position loops over every unused index. Undo both used and path.

Python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        res = []
        used = [False] * len(nums)

        def backtrack(path):
            if len(path) == len(nums):
                res.append(path.copy())
                return

            for i in range(len(nums)):
                if used[i]:
                    continue

                path.append(nums[i])
                used[i] = True
                backtrack(path)
                used[i] = False
                path.pop()

        backtrack([])
        return res

Generate ParenthesesGenerate only choices that remain valid

Open while open_count < n. Close only while close_count < open_count.

Python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        res = []

        def backtrack(open_count, close_count, path):
            if open_count == close_count == n:
                res.append("".join(path))
                return

            if open_count < n:
                path.append("(")
                backtrack(open_count + 1, close_count, path)
                path.pop()

            if close_count < open_count:
                path.append(")")
                backtrack(open_count, close_count + 1, path)
                path.pop()

        backtrack(0, 0, [])
        return res

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        seen = set()
        for num in nums:
            if num not in seen:
                seen.add(num)
        res = 0
        for num in seen:
            if num-1 not in seen:
                count = 0
                candidate = num
                while candidate in seen:
                    count +=1
                    candidate +=1
                res = max(res,count)
        return res

class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        
        nums.sort()
        n = len(nums)
        res = []
        for i in range(n):
            l,r = i+1, n-1
            if i>0 and nums[i] == nums[i-1]:
                continue
            while l<r:
                summ = nums[i] + nums[l] + nums[r]
                if summ > 0:
                    r-=1
                elif summ < 0:
                    l+=1
                else:
                    res.append([nums[i],nums[l],nums[r]])
                    l+=1
                    while l<=r and nums[l]==nums[l-1]:
                        l+=1
        return res

class Solution:
    def maxArea(self, heights: List[int]) -> int:
        
        l,r = 0, len(heights)-1

            area = min(heights[l], heights[r]) * (r-l)

                l+=1
            else:
                r-=1

class Solution:
    def trap(self, height: List[int]) -> int:
        if len(height) < 2:
            return 0

        leftMaxArr = [0 for _ in range(len(height))]
        rightMaxArr = [0 for _ in range(len(height))]

        leftMax = height[0]
        for i in range(1,len(height)):
            leftMaxArr[i] = leftMax
            leftMax = max(leftMax, height[i])

        rightMax = height[-1]
        for i in range(len(height)-2,-1,-1):
            rightMaxArr[i] = rightMax
            rightMax = max(rightMax,height[i])

        allowWater = 0
        for i in range(len(height)):
            minHeight = min(leftMaxArr[i],rightMaxArr[i])
            allowWater += (minHeight-height[i]) if minHeight-height[i] >0 else 0
        return allowWater

Build Tree

Repeated slicing and inorder.index() make the accepted solution O(n²). An index map plus preorder cursor gives O(n).

Kth Smallest

The accepted solution builds the full inorder array. Iterative inorder can stop after the kth pop and use O(h) space.

Subtree

Direct comparison is O(nm) worst case. Serialization or subtree hashing is the next advanced variant.

Traversal robustness

Your mix of BFS and DFS is strong. Iterative DFS is the next gap for avoiding Python recursion-depth limits.

Invert Binary Tree BFS transform · Easy

Your invariant: Swap children before enqueuing them Complexity: O(n) time, O(w) space. Latest accepted: 07/12/2025

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None
        queue = deque([root])

        while queue:
            node = queue.popleft()
            node.left,node.right = node.right,node.left

            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        return root
Maximum Depth of Binary Tree Iterative DFS stack · Easy

# Definition for a binary tree node.

#         self.left = left
#         self.right = right

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:

        stack = [[root,1]]
        res = 0
        while stack:
            node, depth = stack.pop()
            if node:
                res = max(res, depth)
                stack.append([node.left, depth+1])
                stack.append([node.right, depth+1])

        return res
Diameter of Binary Tree Postorder height + global maximum · Easy

Your invariant: Return height; update left height + right height Complexity: O(n) time, O(h) space. Latest accepted: 07/12/2025

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        
        globalmax = 0
        def dfs(node):
            nonlocal globalmax
            if not node:
                return 0

            left = dfs(node.left)
            right = dfs(node.right)

            globalmax = max(globalmax, left + right)
            return 1 + max(left,right)

        dfs(root)
        return globalmax

class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:


        def dfs(node):
            if not node:
                return 0, True

            lheight,lbalanced = dfs(node.left)
            rheight, rbalanced = dfs(node.right)

            height = 1 + max(lheight,rheight)
            isbalanced = True if lbalanced and rbalanced and abs(lheight- rheight) <=1 else False

            return height,isbalanced

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isSameTree(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:

        p1 = deque([p])
        q1 = deque([q])

        while p1 and q1:
            for _ in range(len(p1)):
                pnode = p1.popleft()
                qnode = q1.popleft()

                if pnode is None and qnode is None:
                    continue
                if pnode is None or qnode is None or pnode.val != qnode.val:
                    return False
                
                p1.append(pnode.left)
                p1.append(pnode.right)
                q1.append(qnode.left)
                q1.append(qnode.right)
        return True

        if root is None and subRoot:
            return False

            return True

        if p.val != q.val:
            return False
        return self.isSame(p.left,q.left) and self.isSame(p.right, q.right)

# Definition for a binary tree node.

#     def __init__(self, val=0, left=None, right=None):

#         self.left = left
#         self.right = right

class Solution:
    def lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        
        if not root or not p or not q:
            return None

        if (p.val < root.val and q.val < root.val):
            return self.lowestCommonAncestor(root.left,p,q)
        elif (p.val > root.val and q.val > root.val):
            return self.lowestCommonAncestor(root.right,p,q)
        else:
            return root

                return

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        
        def isValid(node, leftB, rightB):
            if not node:
                return True

            if node.val > leftB and node.val < rightB:
                return (isValid(node.left, leftB, node.val) and
                isValid(node.right, node.val, rightB))
            else:
                return False
        
        return isValid(root, float("-inf"), float("inf"))
