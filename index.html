Algorithm 01

Binary Search

Find a monotonic boundary. Save a valid midpoint, then move toward the first or last valid index.

Boundary framework

The reusable setup stays the same.

First valid: save m, search left. Last valid: save m, search right.

Before using the template

Your predicate must pass both checks.

  • 1
    Fixed

    valid(i) keeps the same meaning while l and r move.

  • 2
    Monotonic

    The results have exactly one boundary: F...T or T...F.

The operator does not decide FIRST or LAST. The boolean shape decides it.

PredicateExampleResult
nums[i] >= target [1,3,5,7,9] -> F F F T T target = 7 First valid First True is index 3, value 7. Save and go left.
nums[i] <= target [1,3,5,7,9] -> T T T F F target = 5 Last valid Last True is index 2, value 5. Save and go right.
nums[i] <= nums[r] The value of r moves during the search. Not fixed
Exact target

The boundary gives a candidate. Verify it afterward: ans != -1 and nums[ans] == target.

Rotated sorted arrays

First find the rotation boundary, then search one sorted side.

Distinct values

Keep last = nums[-1] fixed. The first value satisfying nums[i] <= last is the pivot.

[4, 5, 6, 7, 0, 1, 2] -> F F F F T T T

FIRST valid -> rotation boundary

Duplicate values

Copies of last at the beginning create an extra True prefix and break monotonicity.

Before T T F F T T T
->
Skip leading copies of last F F T T T

Check target == last -> skip leading last values -> FIRST nums[i] <= last

Usually O(log n); worst case O(n). The linear worst case is unavoidable with unrestricted duplicates.

Exact target using first valid

Find the first nums[i] >= target, then verify equality.

Python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        l, r = 0, len(nums) - 1
        ans = -1

        while l <= r:
            m = l + (r - l) // 2

            if nums[m] >= target:
                ans = m
                r = m - 1
            else:
                l = m + 1

        return ans if ans != -1 and nums[ans] == target else -1
Search in Rotated Sorted Array

Distinct values: find the first nums[i] <= last, choose a sorted side, then run last-valid search.

Python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        l, r = 0, len(nums) - 1
        last = nums[-1]
        pivot = -1

        while l <= r:
            m = l + (r - l) // 2
            if nums[m] <= last:
                pivot = m
                r = m - 1
            else:
                l = m + 1

        if nums[pivot] <= target <= nums[-1]:
            l, r = pivot, len(nums) - 1
        else:
            l, r = 0, pivot - 1

        ans = -1
        while l <= r:
            m = l + (r - l) // 2
            if nums[m] <= target:
                ans = m
                l = m + 1
            else:
                r = m - 1

        return ans if ans != -1 and nums[ans] == target else -1
Search in Rotated Sorted Array II

Duplicates: remove the unwanted True prefix before applying the same boundary framework.

Python
class Solution:
    def search(self, nums: List[int], target: int) -> bool:
        end = len(nums) - 1
        last = nums[end]

        if target == last:
            return True

        start = 0
        while start < end and nums[start] == last:
            start += 1

        # First nums[i] <= last
        l, r = start, end
        pivot = -1

        while l <= r:
            m = l + (r - l) // 2
            if nums[m] <= last:
                pivot = m
                r = m - 1
            else:
                l = m + 1

        if target < last:
            l, r = pivot, end
        else:
            l, r = start, pivot - 1

        # Last nums[i] <= target
        ans = -1

        while l <= r:
            m = l + (r - l) // 2
            if nums[m] <= target:
                ans = m
                l = m + 1
            else:
                r = m - 1

        return ans != -1 and nums[ans] == target
