Search range: first True, then last True

Find the first and last index of target in a nondecreasing array, including empty arrays and duplicate runs.

Reuse the existing inclusive boundary framework twice, rather than inventing a duplicate search.

Search only inclusive [l,r], with ans=-1 until a qualifying midpoint is seen. First search: nums[m]>=target is False...True, save m and move r left. Last search: nums[m]<=target is True...False, save m and move l right.

How to use it

  1. Find first True for nums[m]>=target with l<=r and ans=-1.
  2. If first is -1 or nums[first]!=target, return [-1,-1].
  3. Reset bounds and ans; find last True for nums[m]<=target.

Walk through an example

[1,2,2,2,4], target=2: first (l,r,m,ans): (0,4,2,2)->(0,1,0,2)->(1,1,1,1). Last: (0,4,2,2)->(3,4,3,3)->(4,4,4,3). Result [1,3].

The first >= boundary finds the first possible occurrence; equality verification rules out an absent target. Once the target exists, the last <= boundary gives the final occurrence. Both searches use exactly the framework above.

Watch for: First >= can land on a larger value, so verify equality before searching the last boundary. A last <= candidate alone can be smaller than target. Do not mix inclusive bounds with half-open updates.

Complexity: n array items: O(log(n+1)) comparisons for nonempty input, O(1) for empty; O(1) auxiliary space. Each iteration discards at least half the candidate interval up to rounding. Index arithmetic and value comparisons assumed O(1); sortedness is a precondition, not checked with an O(n) scan.

Practice the same idea

Change >= to > to find first strictly greater; change <= to < to find last strictly smaller. Keep the direction of the True region matched to the boundary update. bisect_left/right encode related insertion positions, but use this existing ans=-1 framework here.

def searchRange(nums, target):
    l, r, ans = 0, len(nums) - 1, -1
    while l <= r:
        m = l + (r - l) // 2
        if nums[m] >= target:
            ans = m
            r = m - 1
        else:
            l = m + 1
    first = ans
    if first == -1 or nums[first] != target:
        return [-1, -1]
    l, r, ans = 0, len(nums) - 1, -1
    while l <= r:
        m = l + (r - l) // 2
        if nums[m] <= target:
            ans = m
            l = m + 1
        else:
            r = m - 1
    return [first, ans]

Algorithm 02

Backtracking

Build one candidate step by step. Explore each valid choice, then undo it so the next branch starts clean.

How to think Framework Visualize Decisions Problem map Solutions Tree maze

How to think inside dfs

Focus on one call, not the entire recursion tree.

dfs(state, path)

path is what you have built. state tells you where you are and which choices remain.

  • 1
    Stop

    If path is complete, save path.copy() and return.

  • 2
    Choose and explore

    Add one valid choice, update state, and recurse.

  • 3
    Undo

    Remove the choice so the next branch starts from the same path.

Concrete example

dfs(1, [1]) means: "I chose 1. Now decide whether to take or skip nums[1]."

One framework

Each problem changes the state, choices, completion rule, and pruning rule.

Universal backtracking template
res = []

def backtrack(state, path):
    if complete(state, path):
        res.append(path.copy())
        return

    for choice in choices(state, path):
        if not valid(choice, state, path):
            continue

        path.append(choice)                    # choose
        next_state = apply(choice, state)

        backtrack(next_state, path)             # explore

        undo(choice, state)                    # if state is mutable
        path.pop()                             # undo path

backtrack(initial_state, [])
return res

Keep the first successful root-to-leaf path

Find one root-to-leaf route through a proper binary tree whose value-0 nodes are blocked.

Write a breadcrumb when entering; erase it only if that branch fails.

On entry, path contains the unblocked ancestors of the candidate node. A False return restores exactly that incoming path; a True return preserves the complete successful root-to-leaf path. A leaf has no children in the original tree, not merely no unblocked children.

The reusable pattern

Pattern template · adapt names and helpers to the problem
def search(node, path):
    if node is None or node.val == 0:
        return False
    path.append(node.val)
    if node.left is None and node.right is None:
        return True
    if search(node.left, path) or search(node.right, path):
        return True
    path.pop()  # Only a failed branch is undone.
    return False

How to use it

  1. Reject None or value 0 without changing path; otherwise append the node's value.
  2. Return True at an original leaf or if a left/right recursive call succeeds, preserving the successful path.
  3. If both branches fail, pop this node and return False; a proper tree needs no visited set.

Walk through an example

       1
      / \
     2   3
    /   / \
   0   0   4
[] -> [1] -> [1,2]; blocked 0, missing child -> pop 2.
[1] -> [1,3]; blocked 0 -> [1,3,4]; leaf -> keep path.
Result: [1, 3, 4].

Watch for: Unconditionally popping after success erases the answer. A node whose children are blocked is not a leaf. No visited set is needed only because this is a proper tree; a graph may have cycles or shared nodes and requires visited-state handling.

Complexity: For n tree nodes and node-height h, worst-case time is O(n), recursive stack space O(h), and the retained path uses O(h) space. Search stops after the first successful leaf. Highly skewed trees may exceed Python's recursion limit.

Practice the same idea

Unlike enumerating subsets or permutations, this is a find-one search: failure rolls back, success deliberately commits the path. Duplicate node values are fine for existence, but store node references if route identity matters.

class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        res = []
        used = [False] * len(nums)

        def backtrack(path):
            if len(path) == len(nums):
                res.append(path.copy())
                return

            for i in range(len(nums)):
                if used[i]:
                    continue

                path.append(nums[i])
                used[i] = True
                backtrack(path)
                used[i] = False
                path.pop()

        backtrack([])
        return res

class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        res = []

        def backtrack(open_count, close_count, path):
            if open_count == close_count == n:
                res.append("".join(path))
                return

            if open_count < n:
                path.append("(")
                backtrack(open_count + 1, close_count, path)
                path.pop()

            if close_count < open_count:
                path.append(")")
                backtrack(open_count, close_count + 1, path)
                path.pop()

        backtrack(0, 0, [])
        return res

Kadane: best ending here, best anywhere

Find the maximum sum of a nonempty contiguous subarray, including all-negative input.

At each value, choose exactly one: extend the previous segment or start fresh.

After processing index i, ending is the best nonempty sum ending exactly at i; best is the best nonempty sum anywhere in [0, i].

The reusable pattern

Pattern template · adapt names and helpers to the problem
ending = best = nums[0]  # Nonempty input.
for i in range(1, len(nums)):
    ending = max(nums[i], ending + nums[i])
    best = max(best, ending)
# ending: best ending HERE
# best: best found ANYWHERE

How to use it

  1. Reject empty input; initialize both states from the first value.
  2. Set ending = max(value, ending + value).
  3. Set best = max(best, ending).

Walk through an example

value:   -4   3  -1   4  -7   2
ending:  -4   3   2   6  -1   2
best:    -4   3   3   6   6   6
winner:       [3, -1, 4] -> 6

A nonempty segment ending at the current value has only two possibilities: it starts here, or it extends a segment ending at the previous value. Keeping the better of those two is enough. A separate best records winners that ended earlier.

Watch for: Initializing best to zero silently permits an empty subarray and gives the wrong answer for all-negative input. Updating only ending also loses an earlier winner.

Complexity: Let n be the input length. O(n) time and O(1) auxiliary integer variables, excluding input and printed output. These are unit-cost arithmetic bounds: if intermediate sums have at most B bits, additions/comparisons can take O(B) and the states use O(B) bits. No values[1:] slice is created.

Practice the same idea

Separate 'best ending in this state' from 'best seen globally' in streaming dynamic programming, such as longest valid runs.

Prefix sums: subtract boundaries, count earlier partners

Answer many static range-sum queries or count nonempty subarrays whose sum equals a target.

A subarray sum is the difference between two prefix boundaries, even with negative values.

P[0] = 0 and P[r] is the sum of values[0:r], so sum(values[l:r]) = P[r] - P[l]. Before counting boundary r, frequency holds exactly the earlier prefixes P[0:r].

The reusable pattern

Pattern template · adapt names and helpers to the problem
prefix = [0]
for value in nums:
    prefix.append(prefix[-1] + value)

# Sum of nums[left:right]; right is excluded.
answer = prefix[right] - prefix[left]

How to use it

  1. Build P from a leading zero by adding each value.
  2. For [l, r), subtract P[l] from P[r].
  3. For counting, look up P[r]-target before storing P[r].

Walk through an example

values:        2  -2   3  -1   2
boundary:  0   1   2   3   4   5
P:         0   2   0   3   2   4
[1,4): P[4]-P[1] = 2-2 = 0
target 2, matches added: 1, 0, 0, 2, 2 -> 5

Both prefixes start at index zero. Subtracting the prefix before left cancels everything before the desired range. Keeping frequencies of earlier prefixes extends the same identity to counting matching subarrays, even when values are negative.

Watch for: Store the current prefix only after lookup, or target zero counts an empty subarray. Store frequencies, not a set: duplicate prefixes represent distinct starting boundaries. Ordinary sum-based sliding windows are not reliable with signed values.

Complexity: Let n be the input length. Prefix construction is O(n) time and O(n) integer storage; each validated range query is O(1). Counting is expected O(n) time and O(n) stored prefixes, but can be O(n^2) with pathological dictionary collisions. Excludes printing. Bounds assume unit-cost integer arithmetic and hashing; Python sums, target differences, and counts can grow in bit length, increasing arithmetic, hash, and storage costs.

def prefixes(values):
    prefix = [0]
    for value in values:
        prefix.append(prefix[-1] + value)
    return prefix

def range_sum(prefix, left, right):
    if not 0 <= left <= right < len(prefix):
        raise IndexError('invalid half-open range')
    return prefix[right] - prefix[left]

def count_sum(values, target):
    frequency = {0: 1}
    total = answer = 0
    for value in values:
        total += value
        answer += frequency.get(total - target, 0)

Hash maps: choose a bucket, then check equality

Use this small separate-chaining model to understand collisions, replacement, deletion, and growth; use Python dict for real applications.

Two keys can share a hash without being the same key.

Each live key appears once in bucket hash(key) % bucket_count; size counts entries, not occupied buckets. Equal keys must have equal stable hashes, but equal hashes do not imply equal keys. The frozen test keys deliberately all hash to 1.

The reusable pattern

Pattern template · adapt names and helpers to the problem
index = hash(key) % len(buckets)
for stored_key, value in buckets[index]:
    if stored_key == key:
        return value
# Same bucket does not mean same key.
raise KeyError(key)

How to use it

  1. Choose a bucket and scan its entries using key equality.
  2. Replace an equal key, delete its entry, or add one new entry.
  3. Before exceeding load 1, double buckets and redistribute every entry.

Walk through an example

buckets 2:  0: []  1: [(1,10), (2,20)]
insert 3 -> buckets 4, all hashes still 1:
            0: []  1: [(1,10), (2,20), (3,30)]
replace 2:         [(1,10), (2,200), (3,30)]
delete 1:          [(2,200), (3,30)]

Watch for: Resizing changes the bucket modulus, so entries must be redistributed. Replacement must not increment size. Do not use hash equality as key equality or assume growth fixes identical hashes. This toy is not CPython dict's implementation.

Complexity: Let n be live entries and B the bucket count. Assuming well-distributed hashes, constant-time hash/equality/index arithmetic, and bounded load, lookup/deletion are expected O(1) and insertion is expected amortized O(1). Any single operation can take O(n+1) worst-case; growth costs O(n+B) and occurs when n=B. Direct redistribution avoids equality scans during rehash. Storage is O(n+B), with O(n+B) extra during growth. There is no shrinking: B reflects peak size, not current n. Excludes printing and key/value object storage. Python integer hashing/equality/arithmetic may depend on operand bit length. Our constant-hash test intentionally demonstrates the O(n) collision case, not the average case.

from dataclasses import dataclass

@dataclass(frozen=True)
class Key:
    number: int

    def __hash__(self):
        return 1  # Deliberate collisions, stable across runs.

class ChainedMap:
    def __init__(self):
        self.buckets = [[], []]
        self.size = 0

    def _bucket(self, key):
        return self.buckets[hash(key) % len(self.buckets)]

    def _grow(self):
        old = self.buckets
        self.buckets = [[] for _ in range(2 * len(old))]
        for bucket in old:
            for key, value in bucket:
                self._bucket(key).append((key, value))

    def put(self, key, value):
        bucket = self._bucket(key)
        for i, (stored, _) in enumerate(bucket):
            if stored == key:
                bucket[i] = (stored, value)
                return
        if self.size == len(self.buckets):
            self._grow()
            bucket = self._bucket(key)
        bucket.append((key, value))
        self.size += 1

    def get(self, key):
        for stored, value in self._bucket(key):
            if stored == key:
                return value
        raise KeyError(key)

    def delete(self, key):
        bucket = self._bucket(key)
        for i, (stored, value) in enumerate(bucket):
            if stored == key:
                del bucket[i]
                self.size -= 1
                return value
        raise KeyError(key)

    node.prev, node.next = anchor, right

  1. Enqueue with append(value) on the right.
  2. If the queue is nonempty, dequeue with popleft().

popleft:     returns 7; [8]
append 9:    front [8, 9] back

Every recursive call hands back the branch that should occupy its old socket.

    value: object
    left: object = None

class BSTMap:
    def __init__(self):
        self.root = None

    def put(self, key, value):
        def place(node):
            if node is None:
                return Entry(key, value)
            if key < node.key:
                node.left = place(node.left)
            elif key > node.key:
                node.right = place(node.right)
            else:
                node.value = value
            return node
        self.root = place(self.root)

    def get(self, key):
        node = self.root
        while node is not None:
            if key == node.key:
                return node.value
            node = node.left if key < node.key else node.right
        raise KeyError(key)

    def items(self, lo, hi):
        if lo >= hi:
            return
        node, stack = self.root, []
        while node is not None or stack:
            while node is not None:
                if node.key < lo:
                    node = node.right
                else:
                    stack.append(node)
                    node = node.left
            if not stack:
                break
            node = stack.pop()
            if node.key >= hi:
                break
            yield node.key, node.value
            node = node.right

class Trie:
    def __init__(self):
        self.children = {}
        self.terminal = False

    def insert(self, word):

                node.children[char] = Trie()
            node = node.children[char]
        node.terminal = True

        node = self
        for char in text:
            node = node.children.get(char)
            if node is None:
                return None
        return node

        node = self._walk(word)
        return node is not None and node.terminal

        return self._walk(prefix) is not None

            raise ValueError('negative size')
        self.parent = list(range(n))

        self._check(x)

            root = self.parent[root]

            old_parent = self.parent[x]
            self.parent[x] = root
            x = old_parent

            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True

Iterative segment tree: point assignment and range sum

Answer repeated half-open range sums while individual array positions change.

Leaves hold individual values; a query takes whole sibling blocks whenever they fit.

Round leaf capacity up to a power of two and fill unused leaves with identity 0. Every node now summarizes one contiguous interval; each parent is the sum of its two children. During query, the accumulated sum plus the still-pending intervals equals the requested sum.

The reusable pattern

Pattern template · adapt names and helpers to the problem
# Leaves hold values; parents combine adjacent intervals.
tree[parent] = tree[2 * parent] + tree[2 * parent + 1]

# Point assignment: replace leaf, then repair its ancestors.
tree[position] = new_value
while position > 1:
    position //= 2
    tree[position] = tree[2 * position] + tree[2 * position + 1]

How to use it

  1. Choose power-of-two capacity size, place values at offset size, and build parent sums; unused leaves stay 0.
  2. For point set, replace one leaf and recompute ancestors; this is assignment, not increment.
  3. For [left,right), consume an odd left boundary and an odd right boundary before moving both boundaries to their parents.

set(2,10): t6=10, t3=14, t1=17.
query(1,4) -> 15; query(2,2) -> 0.

A point update changes only intervals containing that point, which lie on one root path. A range query takes complete blocks wherever possible instead of visiting every value; at each level only the two boundary blocks may need refinement.

Watch for: right is excluded, and set replaces the previous value. Segment trees require an associative combine operation and its identity, not an inverse: sum uses 0, min uses +infinity. This single-accumulator implementation exploits commutative addition; noncommutative operations need separate ordered left/right accumulators.

Complexity: For n nonempty input values, n <= size < 2n, so power-of-two padding still gives O(n) build time and storage. Point set and range query take O(log n) time for n >= 2, O(1) for n <= 1, and O(1) auxiliary space. An empty tree uses O(1) storage and accepts only query(0,0); no point index is valid.

class SegmentTree:
    def __init__(self, values):
        self.n = len(values)
        self.size = 1
        while self.size < self.n:
            self.size *= 2
        self.t = [0] * (2 * self.size)
        self.t[self.size:self.size + self.n] = values
        for p in range(self.size - 1, 0, -1):
            self.t[p] = self.t[2 * p] + self.t[2 * p + 1]

    def set(self, index, value):
        if not 0 <= index < self.n:
            raise IndexError('index out of bounds')
        p = self.size + index
        self.t[p] = value
        while p > 1:
            p //= 2
            self.t[p] = self.t[2 * p] + self.t[2 * p + 1]

    def query(self, left, right):
        if not 0 <= left <= right <= self.n:
            raise IndexError('invalid half-open range')
        left, right = left + self.size, right + self.size
        total = 0
        while left < right:
            if left % 2:
                total += self.t[left]
                left += 1
            if right % 2:
                right -= 1
                total += self.t[right]
            left //= 2
            right //= 2
        return total

01. StrategySwap fees without rewriting checkout
Behavioral

Maya opens Neighborhood Kitchen and starts taking both pickup and delivery orders from her tiny storefront. Every order needs a fulfillment fee, and she wants to add catering later without rewriting checkout.

Before: what becomes awkward?

After: the design move

Extract the interchangeable fee algorithms behind IFeePolicy and inject a policy into Checkout. Checkout owns totaling and delegates just the fee decision.

Program.Main is the client that constructs two separate checkouts and calls them sequentially. Neither checkout changes its policy; “interchangeable” means either implementation fits the same contract.

{
    int FeeCents(int subtotalCents);
}

{
    public int FeeCents(int subtotalCents) => 0;
}

public sealed class Delivery : IFeePolicy
{

    public Delivery(int feeCents)
    {
        if (feeCents < 0) throw new ArgumentOutOfRangeException(nameof(feeCents));
        this.feeCents = feeCents;
    }
    public int FeeCents(int subtotalCents) => feeCents;
}

public sealed class Checkout
{
    private readonly IFeePolicy policy;
    public Checkout(IFeePolicy policy)
    {
        this.policy = policy ?? throw new ArgumentNullException(nameof(policy));
    }
    public int TotalCents(int subtotalCents)
    {
        if (subtotalCents < 0) throw new ArgumentOutOfRangeException(nameof(subtotalCents));
        return checked(subtotalCents + policy.FeeCents(subtotalCents));
    }
}

using System.Collections;
using System.Collections.Generic;

public interface IOrderLine
{
    IEnumerable<Dish> Dishes();
}

public sealed record Dish(string Name, int PriceCents) : IOrderLine
{
    public IEnumerable<Dish> Dishes()
    {
        yield return this;
    }
}

public sealed class Bundle : IOrderLine
{
    private readonly IOrderLine[] children;
    public Bundle(params IOrderLine[] children)
    {
        this.children = (IOrderLine[])children.Clone();
    }
    public IEnumerable<Dish> Dishes()
    {
        foreach (IOrderLine child in children)
            foreach (Dish dish in child.Dishes())
                yield return dish;
    }
}

public sealed class Order : IEnumerable<Dish>
{
    private readonly IOrderLine[] lines;
    public Order(params IOrderLine[] lines)
    {
        this.lines = (IOrderLine[])lines.Clone();
    }
    public IEnumerator<Dish> GetEnumerator()
    {
        foreach (IOrderLine line in lines)
            foreach (Dish dish in line.Dishes())
                yield return dish;
    }
    IEnumerator IEnumerable.GetEnumerator() => GetEnumerator();
}

{

using System;
using System.Collections.Generic;
using System.Linq;

public interface ICommand
{
    void Execute();
    void Undo();
}

public sealed class Draft
{
    private readonly List<(string Name, int Cents)> lines = new();
    public int TotalCents => lines.Sum(line => line.Cents);
    public string Items => string.Join(", ", lines.Select(line => line.Name));
    public void Add(string name, int cents)
    {
        if (cents < 0) throw new ArgumentOutOfRangeException(nameof(cents));
        lines.Add((name, cents));
    }
    public void RemoveLast() => lines.RemoveAt(lines.Count - 1);
}

public sealed class AddDishCommand(Draft receiver, string name, int cents) : ICommand
{
    public void Execute() => receiver.Add(name, cents);
    public void Undo() => receiver.RemoveLast();
}

public sealed class EditQueue
{
    private readonly Queue<ICommand> pending = new();
    private readonly Stack<ICommand> history = new();
    public int Pending => pending.Count;
    public void Enqueue(ICommand command) => pending.Enqueue(command);
    public void RunNext()
    {
        ICommand command = pending.Peek();
        command.Execute();
        pending.Dequeue();
        history.Push(command);
    }
    public void UndoLast()
    {
        ICommand command = history.Peek();
        command.Undo();
        history.Pop();
    }
}

public static class Program
{
    public static void Main()
    {
        var draft = new Draft();
        var terminal = new EditQueue();
        terminal.Enqueue(new AddDishCommand(draft, "Soup", 700));
        terminal.Enqueue(new AddDishCommand(draft, "Salad", 550));
        if (draft.TotalCents != 0 || terminal.Pending != 2)
            throw new Exception("Enqueue must not execute.");
        Console.WriteLine($"queued={terminal.Pending} total={draft.TotalCents}");
        terminal.RunNext();
        terminal.RunNext();
        if (draft.TotalCents != 1250 || terminal.Pending != 0)
            throw new Exception("FIFO execution failed.");
        Console.WriteLine($"executed={draft.Items} total={draft.TotalCents}");
        terminal.UndoLast();
        if (draft.Items != "Soup" || draft.TotalCents != 700)
            throw new Exception("Undo must remove the latest edit.");
        Console.WriteLine($"undo={draft.Items} total={draft.TotalCents}");
    }

Behavioral

Before: what becomes awkward?

using System;
using System.Collections.Generic;

public interface IDraftSnapshot { }

public sealed class Draft
{
    private sealed class Snapshot(Draft owner, string items, int total) : IDraftSnapshot
    {
        public readonly Draft Owner = owner;
        public readonly string Items = items;
        public readonly int TotalCents = total;
    }
    public string Items { get; private set; } = "";
    public int TotalCents { get; private set; }
    public bool Submitted { get; private set; }
    private void RequireUnsent()
    {
        if (Submitted) throw new InvalidOperationException("Draft already submitted.");
    }
    public void Replace(string items, int totalCents)
    {
        RequireUnsent();
        if (totalCents < 0) throw new ArgumentOutOfRangeException(nameof(totalCents));
        Items = items;
        TotalCents = totalCents;
    }
    public IDraftSnapshot Save()
    {
        RequireUnsent();
        return new Snapshot(this, Items, TotalCents);
    }
    public void Restore(IDraftSnapshot snapshot)
    {
        RequireUnsent();
        if (snapshot is not Snapshot saved || !ReferenceEquals(saved.Owner, this))
            throw new InvalidOperationException("Foreign snapshot.");
        Items = saved.Items;
        TotalCents = saved.TotalCents;
    }
    public void Submit() { RequireUnsent(); Submitted = true; }
}

public sealed class Caretaker(Draft draft)
{
    private readonly Stack<IDraftSnapshot> history = new();
    public int Count => history.Count;
    public void Checkpoint() => history.Push(draft.Save());
    public void Undo()
    {
        draft.Restore(history.Peek());
        history.Pop();
    }
}

public static class Program
{
    private static bool Rejected(Action action)
    {
        try { action(); return false; }
        catch (InvalidOperationException) { return true; }
    }
    public static void Main()
    {
        var draft = new Draft();
        var history = new Caretaker(draft);
        draft.Replace("Soup", 700);
        history.Checkpoint();
        bool foreign = Rejected(() => new Draft().Restore(draft.Save()));
        draft.Replace("Soup, Salad", 1250);
        history.Undo();
        if (!foreign || draft.Items != "Soup" || draft.TotalCents != 700)
            throw new Exception("Snapshot restoration failed.");
        Console.WriteLine($"restored={draft.Items} total={draft.TotalCents} foreign={foreign}");
        history.Checkpoint();
        draft.Submit();
        bool undoBlocked = Rejected(history.Undo);
        bool saveBlocked = Rejected(() => draft.Save());
        bool editBlocked = Rejected(() => draft.Replace("Tea", 300));
        if (!undoBlocked || !saveBlocked || !editBlocked || history.Count != 1)
            throw new Exception("Submission boundary failed.");
        Console.WriteLine($"submitted={draft.Submitted} undoBlocked={undoBlocked} history={history.Count}");
    }
}

09. StateChange behavior by changing active state
Behavioral

Maya gives Neighborhood Kitchen orders three explicit stages: Draft while staff edit, Accepted when the kitchen receives the ticket, and Cooking when preparation begins. Each stage must change the behavior of the same order methods, rather than merely change a status label.

Before: what becomes awkward?

A status string and scattered conditional checks let editing and stage progression disagree about which actions are legal.

Before · illustrative fragment

using System;

public sealed class Order
{
    private OrderState state = new DraftState();
    public int TotalCents { get; private set; }
    public string Stage => state.Name;
    public void AddDish(int cents)
    {
        if (cents < 0) throw new ArgumentOutOfRangeException(nameof(cents));
        state.AddDish(this, cents);
    }
    public void Advance() => state.Advance(this);

    private abstract class OrderState
    {
        public abstract string Name { get; }
        public virtual void AddDish(Order order, int cents) =>
            throw new InvalidOperationException($"Editing blocked in {Name}.");
        public virtual void Advance(Order order) =>
            throw new InvalidOperationException($"No next stage from {Name}.");
    }
    private sealed class DraftState : OrderState
    {
        public override string Name => "Draft";
        public override void AddDish(Order order, int cents)
        {
            order.TotalCents = checked(order.TotalCents + cents);
        }
        public override void Advance(Order order)
        {
            if (order.TotalCents == 0)
                throw new InvalidOperationException("Add a priced dish first.");
            order.state = new AcceptedState();
            Console.WriteLine($"ticket accepted: {order.TotalCents} cents");
        }
    }
    private sealed class AcceptedState : OrderState
    {
        public override string Name => "Accepted";
        public override void Advance(Order order)
        {
            order.state = new CookingState();
            Console.WriteLine("start cooking: ticket locked");
        }
    }
    private sealed class CookingState : OrderState
    {
        public override string Name => "Cooking";
    }
}

        steps.Add(Gather());
        steps.Add(PrepareFood());
        if (NeedsGarnish) steps.Add(Garnish());

        return steps.AsReadOnly();

    protected abstract string PrepareFood();

}

public sealed record ReadyOrder(int Id, string Shelf);

public sealed class Kitchen
{
    private readonly HashSet<int> ready = new();
    public event Action<ReadyOrder>? OrderReady;
    public bool IsReady(int id) => ready.Contains(id);

        Chef = new Chef(this); Packer = new Packer(this); Courier = new Courier(this);

        return true;

    {
        if (sender == Chef && signal == Signal.Prepared && Stage == Stage.Cooking)

            Stage = Stage.AwaitingCourier; Courier.Receive(OrderId, "collect"); return true;

            return false;
        Stage = Stage.Complete;

using System.Collections.Generic;

public interface IStatusSource
{
    string GetStatus(int bookingId);
}
public interface IClock
{
    DateTimeOffset UtcNow { get; }
}
public sealed class FakeClock : IClock
{
    public DateTimeOffset UtcNow { get; private set; } =
        new DateTimeOffset(2026, 9, 10, 12, 0, 0, TimeSpan.Zero);
    public void Advance(TimeSpan elapsed)
    {
        if (elapsed < TimeSpan.Zero) throw new ArgumentOutOfRangeException(nameof(elapsed));
        UtcNow += elapsed;
    }
}

public sealed class KitchenStatusSource : IStatusSource
{
    private readonly Dictionary<int, string> statuses = new();
    public int Reads { get; private set; }
    public void SetStatus(int id, string status) => statuses[id] = status;
    public string GetStatus(int bookingId)
    {
        Reads++;
        return statuses[bookingId];
    }
}

public sealed class StatusProxy : IStatusSource
{
    private sealed record Entry(string Status, DateTimeOffset ExpiresAt);
    private readonly Dictionary<int, Entry> cache = new();
    private readonly IStatusSource source;
    private readonly IClock clock;
    private readonly TimeSpan ttl;
    public StatusProxy(IStatusSource source, IClock clock, TimeSpan ttl)
    {
        if (ttl <= TimeSpan.Zero) throw new ArgumentOutOfRangeException(nameof(ttl));
        this.source = source; this.clock = clock; this.ttl = ttl;
    }
    public string GetStatus(int bookingId)
    {
        if (cache.TryGetValue(bookingId, out Entry? entry) && clock.UtcNow < entry.ExpiresAt)
            return entry.Status;
        string status = source.GetStatus(bookingId);
        cache[bookingId] = new Entry(status, clock.UtcNow + ttl);
        return status;
    }
    public void Invalidate(int bookingId) => cache.Remove(bookingId);
}

using System;
using System.Linq;

// Grammar: rule := subtotal >= CENTS | zone = NAME
//                | (rule AND rule) | (rule OR rule)
// Hand-built AST only: no parser, eval, or runtime code compilation.
public sealed record OrderContext(int SubtotalCents, string Zone);

public interface IRule
{
    bool Evaluate(OrderContext context);
}

public sealed record SubtotalAtLeast(int Cents) : IRule
{
    public bool Evaluate(OrderContext context) => context.SubtotalCents >= Cents;
}

public sealed record ZoneIs(string Name) : IRule
{
    public bool Evaluate(OrderContext context) =>
        string.Equals(context.Zone, Name, StringComparison.Ordinal);
}

public sealed record And(IRule Left, IRule Right) : IRule
{
    public bool Evaluate(OrderContext context) =>
        Left.Evaluate(context) && Right.Evaluate(context);
}

public sealed record Or(IRule Left, IRule Right) : IRule
{
    public bool Evaluate(OrderContext context) =>
        Left.Evaluate(context) || Right.Evaluate(context);
}

public static class Program
{
    public static void Main()
    {
        IRule perk = new Or(
            new And(new SubtotalAtLeast(5000), new ZoneIs("near")),
            new SubtotalAtLeast(10000));
        OrderContext[] orders =
        [
            new(6000, "near"),
            new(6000, "far"),
            new(10000, "far")
        ];
        bool[] eligible = orders.Select(order => perk.Evaluate(order)).ToArray();
        bool belowThreshold = perk.Evaluate(new OrderContext(4999, "near"));
        bool atThreshold = perk.Evaluate(new OrderContext(5000, "near"));
        if (!eligible.SequenceEqual(new[] { true, false, true }))
            throw new InvalidOperationException("Eligibility mismatch");
        if (belowThreshold || !atThreshold)
            throw new InvalidOperationException("Boundary mismatch");
        Console.WriteLine($"Eligible: {string.Join(", ", eligible)}");
        Console.Write($"Near 4999: {belowThreshold}; near 5000: {atThreshold}");
    }
}

using System;
using System.Collections.Generic;
using System.Linq;

public interface IMenuItem
{
    T Accept<T>(IMenuVisitor<T> visitor);
}

public interface IMenuVisitor<T>
{
    T Visit(Dish dish);
    T Visit(Bundle bundle);
}

public sealed record Dish(string Name, int UnitCents, int Quantity) : IMenuItem
{
    public T Accept<T>(IMenuVisitor<T> visitor) => visitor.Visit(this);
}

public sealed class Bundle : IMenuItem
{
    public string Name { get; }
    public IReadOnlyList<IMenuItem> Children { get; }
    public Bundle(string name, params IMenuItem[] children)
    {
        Name = name;
        Children = Array.AsReadOnly(children.ToArray());
    }
    // Dispatch only: recursion belongs to the visitor.
    public T Accept<T>(IMenuVisitor<T> visitor) => visitor.Visit(this);
}

public sealed class TotalVisitor : IMenuVisitor<int>
{
    public int Visit(Dish dish) => checked(dish.UnitCents * dish.Quantity);
    public int Visit(Bundle bundle) =>
        bundle.Children.Sum(child => child.Accept(this));
}

public sealed class PackingVisitor : IMenuVisitor<IReadOnlyList<string>>
{
    public IReadOnlyList<string> Visit(Dish dish) =>
        new List<string> { $"{dish.Name} x{dish.Quantity}" }.AsReadOnly();
    public IReadOnlyList<string> Visit(Bundle bundle)
    {
        var entries = new List<string>();
        foreach (IMenuItem child in bundle.Children)
            entries.AddRange(child.Accept(this));
        return entries.AsReadOnly();
    }
}

        Console.WriteLine($"Total cents: {total}");
        Console.Write("Packing: " + string.Join(", ", packing));
    }

using System;
using System.Collections.Generic;
using System.Collections.ObjectModel;
using System.Linq;

public sealed record Ingredient(string Name, int Amount);

public sealed record RecipeSpec
{
    public string Name { get; }
    public int Version { get; }
    public ReadOnlyCollection<Ingredient> Ingredients { get; }
    public RecipeSpec(string name, int version, IEnumerable<Ingredient> ingredients)
    {
        Name = name;
        Version = version;
        Ingredients = Array.AsReadOnly(ingredients.ToArray());
    }
}

public sealed class RecipePool
{
    private readonly Dictionary<(string Name, int Version), RecipeSpec> specs = new();
    public int Count => specs.Count;
    public RecipeSpec Get(string name, int version, IEnumerable<Ingredient> ingredients)
    {
        var key = (name, version);
        Ingredient[] snapshot = ingredients.ToArray();
        if (specs.TryGetValue(key, out RecipeSpec? existing))
        {
            if (!existing.Ingredients.SequenceEqual(snapshot))
                throw new ArgumentException("Changed recipe needs a new version");
            return existing;
        }
        var created = new RecipeSpec(name, version, snapshot);
        specs.Add(key, created);
        return created;
    }
}

public sealed record OrderLine(RecipeSpec Recipe, int Quantity, string Notes, int ChargedUnitCents)
{
    public int TotalCents => checked(Quantity * ChargedUnitCents);
}

}

{

            throw new ArgumentOutOfRangeException(nameof(subtotalCents));

    }
}

Rule: In this toy address model, slot i starts at base + i * width for 0 <= i < size. CPython lists hold a contiguous array of reference slots pointing to objects, not Python integers stored inline. The base and width below are invented, not measured addresses or hardware guarantees.

Static arraysMake a hole; keep the order

Rule: 0 <= size <= capacity. Live values occupy slots [0, size); the suffix is unused. A Python list simulates the fixed backing store: this class never changes its length.

class FixedArray:
    def __init__(self, capacity):
        if capacity < 0:
            raise ValueError('negative capacity')
        self.slots = [None] * capacity
        self.size = 0

    def insert(self, i, value):
        if not 0 <= i <= self.size:
            raise IndexError(i)
        if self.size == len(self.slots):
            raise OverflowError('full')
        for j in range(self.size, i, -1):
            self.slots[j] = self.slots[j - 1]
        self.slots[i] = value
        self.size += 1

    def delete(self, i):
        if not 0 <= i < self.size:
            raise IndexError(i)
        value = self.slots[i]
        for j in range(i, self.size - 1):
            self.slots[j] = self.slots[j + 1]
        self.size -= 1
        self.slots[self.size] = None
        return value

buffer = FixedArray(5)
for value in [10, 20, 30]:
    buffer.insert(buffer.size, value)
buffer.insert(1, 15)
assert buffer.slots == [10, 15, 20, 30, None]
print('insert:', buffer.slots, 'size:', buffer.size)
removed = buffer.delete(2)
assert removed == 20 and buffer.size == 3
print('delete:', buffer.slots, 'capacity:', len(buffer.slots))
empty = FixedArray(0)
try:
    empty.insert(0, 7)
except OverflowError:
    print('full: OverflowError')
else:
    raise AssertionError('full buffer accepted insertion')

Watch for: Shift right from the end or you overwrite values not yet copied. None is only a cleared-slot marker: size, not value equality with None, decides which slots are live.

Complexity details: Let n be the size before an operation, C the fixed capacity, and i a valid logical index. Initialization takes O(C) time and O(C) reference storage. Direct slot access is O(1). Insertion shifts n-i references; deletion shifts n-i-1, so either takes O(n-i) time away from the end and O(1) at the end, with O(1) auxiliary space. Excludes printing and stored objects. Index arithmetic is assumed unit-cost on machine-sized integers; arbitrary-size Python arithmetic is not generally constant-time.

Dynamic arraysFull? Grow, copy, then append

Rule: Live references occupy [0, size), with size <= capacity. This teaching implementation starts at capacity 1 and doubles only when full; it makes no claim about CPython's growth factors or hidden list capacity.

Python 3.10+ · complete runnable example
class GrowingArray:
    def __init__(self):
        self.slots = [None]
        self.size = 0

    def append(self, value):
        if self.size == len(self.slots):
            larger = [None] * (2 * len(self.slots))
            for i in range(self.size):
                larger[i] = self.slots[i]
            self.slots = larger
        self.slots[self.size] = value
        self.size += 1

    def __getitem__(self, i):
        if not 0 <= i < self.size:
            raise IndexError(i)
        return self.slots[i]

Watch for: Growing by one slot every time makes m appends cost O(m^2). Amortized O(1) describes a sequence of operations, not a promise that every individual append is fast.

Complexity details: Let n be the current size and m the number of appends starting empty. Indexing takes O(1); append takes O(1) amortized and O(n) worst-case when growing. Across m appends, geometric allocation and copying total O(m). Backing storage is O(n+1) references; a growth temporarily needs O(n) extra references. Excludes printing, demonstration lists, and stored objects. Reference operations and machine-sized index arithmetic are treated as O(1); arbitrary-size Python integers are not unit-cost in general.

Reference

Deeper framework explanation

Maintain 0 <= size <= capacity, with live references in [0, size) and unused storage in [size, capacity). In the fixed-width RAM model, slot i is at base + i * width; this locates a reference slot, not necessarily the referenced object. Access and replacement at a valid index take O(1) under machine-word assumptions, but finding a value in an unsorted array still takes O(n). None can be a live value: the size boundary, not a sentinel value, determines membership.

Preserve the occupied prefix when changing its length. To insert at i, copy the suffix rightward from its end so no unread reference is overwritten; deletion copies leftward from the hole and clears the abandoned last slot. A fixed buffer rejects insertion when full, whereas a dynamic buffer allocates a larger store and copies live references before appending. Geometric growth makes total copying over m appends O(m), hence O(1) amortized append, although a single growth costs O(n); arbitrary-position insertion still shifts O(n-i) references. Doubling below is a teaching policy, not CPython's exact allocation rule.

TEMPLATE: insert into a fixed occupied prefix
def insert_slot(slots, size, i, value):
    # slots is a simulated fixed-capacity backing store.
    if not 0 <= size <= len(slots):
        raise ValueError('invalid size')
    if not 0 <= i <= size:
        raise IndexError(i)
    if size == len(slots):
        raise OverflowError('full')
    for j in range(size, i, -1):
        slots[j] = slots[j - 1]

            pivot = a[(lo + hi) // 2]

                    i += 1

HeapifyChildren first; parents next

Rule: Before processing i from n//2-1 down to 0, both child subtrees of i are heaps. Sifting i down makes its whole subtree a heap without damaging finished descendants.

Python 3.10+ · complete runnable example
import heapq


def heapify_bottom_up(a):
    n = len(a)
    for start in range(n // 2 - 1, -1, -1):
        i = start
        while 2 * i + 1 < n:
            child = 2 * i + 1
            if child + 1 < n and a[child + 1] < a[child]:
                child += 1
            if a[i] <= a[child]:
                break
            a[i], a[child] = a[child], a[i]
            i = child
    return a

import heapq


class MedianStream:
    def __init__(self):
        self.low = []
        self.high = []

    def add(self, x):
        if not self.low or x <= -self.low[0]:
            heapq.heappush(self.low, -x)
        else:
            heapq.heappush(self.high, x)
        if len(self.low) > len(self.high) + 1:
            heapq.heappush(self.high, -heapq.heappop(self.low))
        elif len(self.high) > len(self.low):

Deeper framework explanation

Maintain the min-heap promise that each parent is no greater than its children. In zero-based array storage, children of i are 2*i+1 and 2*i+2, and the parent of a nonroot is (i-1)//2. Following ancestors proves the root is a global minimum, but gives no order between siblings or separate subtrees. Push repairs an upward path and pop repairs a downward path, using O(log n) comparisons; peek is O(1), and bottom-up heapify builds an available batch in O(n). Python list resizing makes operation-time bounds amortized, and neither iteration nor an arbitrary index reveals sorted rank.

Choose what the root represents before choosing heap operations. A priority queue exposes the next task; a size-k min-heap for the largest k exposes the weakest retained candidate. A median structure instead partitions every value between a lower max-heap and an upper min-heap: every lower value must be <= every upper value, and the lower size must equal the upper size or exceed it by one. Both promises are necessary to identify the middle. Python 3.10 heapq is a min-heap API, so negate numeric lower-half values; use a unique sequence number between priority and payload to handle ties without comparing unrelated payload objects.

def island_sizes(grid):

    cols = len(grid[0]) if rows else 0
    if any(len(row) != cols for row in grid):

Rule: A cell's first enqueue fixes its shortest distance because the FIFO queue expands nondecreasing distances and marks cells immediately.

from collections import deque


def shortest_steps(grid, start, goal):
    rows = len(grid)
    cols = len(grid[0]) if rows else 0
    if any(len(row) != cols for row in grid):
        raise ValueError('grid must be rectangular')
    for r, c in (start, goal):
        if not (0 <= r < rows and 0 <= c < cols) or grid[r][c] != 0:
            return -1
    queue = deque([(start[0], start[1], 0)])
    seen = {start}
    while queue:
        r, c, distance = queue.popleft()
        if (r, c) == goal:
            return distance
        for dr, dc in ((0, 1), (1, 0), (0, -1), (-1, 0)):
            nr, nc = r + dr, c + dc
            if not (0 <= nr < rows and 0 <= nc < cols):
                continue
            if grid[nr][nc] == 0 and (nr, nc) not in seen:
                seen.add((nr, nc))
                queue.append((nr, nc, distance + 1))
    return -1

    grid = [[0, 0, 1, 0], [1, 0, 0, 0], [0, 0, 1, 0]]

DijkstraCheapest whole journey first

Rule: dist[v] is the best discovered source-to-v cost. A popped entry is expanded only if it matches dist[v]; with nonnegative weights that current minimum distance is final.

Python 3.10+ · complete runnable example
from heapq import heappop, heappush
from math import inf


def dijkstra(adj, source):
    if not 0 <= source < len(adj):
        raise ValueError('invalid source')
    for neighbors in adj:
        for v, weight in neighbors:
            if not 0 <= v < len(adj):
                raise ValueError('invalid endpoint')
            if weight < 0:
                raise ValueError('negative weight')
    dist = [inf] * len(adj)
    dist[source] = 0
    heap = [(0, source)]
    while heap:
        distance, u = heappop(heap)
        if distance != dist[u]:
            continue
        for v, weight in adj[u]:
            candidate = distance + weight
            if candidate < dist[v]:
                dist[v] = candidate
                heappush(heap, (candidate, v))
    return dist


def main():
    adj = [[(1, 10), (2, 1)], [(3, 1)], [(1, 1), (3, 5)], [], []]
    distances = dijkstra(adj, 0)
    ties = dijkstra([[(1, 1), (2, 1)], [], []], 0)
    assert distances == [0, 2, 1, 3, inf]
    assert ties == [0, 1, 1]
    print('distances:', distances)
    try:
        dijkstra([[], [(1, -1)]], 0)
    except ValueError as error:
        print('rejected:', error)
    else:
        raise AssertionError('negative weight accepted')

    main()

PrimCheapest connection to the tree

Rule: Every accepted non-root heap entry joins a new vertex by a cheapest crossing edge. Entries leading to already visited vertices are discarded.

def prim_forest(adj):
    visited = set()
    chosen = []
    total = 0
    components = 0
    for root in range(len(adj)):
        if root in visited:
            continue
        components += 1
        heap = [(0, root, -1)]
        while heap:
            weight, u, parent = heappop(heap)
            if u in visited:
                continue
            visited.add(u)
            if parent != -1:
                chosen.append((parent, u, weight))
                total += weight
            for v, edge_weight in adj[u]:
                if v not in visited:
                    heappush(heap, (edge_weight, v, u))
    return total, chosen, components

KruskalCheapest edge joining different groups

Rule: The accepted edges are acyclic, and the disjoint-set structure represents exactly their connected components. Each successful union decreases the component count by one.

Python 3.10+ · complete runnable example
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while x != self.parent[x]:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True


def kruskal_forest(vertex_count, edges):
    if vertex_count < 0:
        raise ValueError('vertex_count must be nonnegative')
    ordered = sorted(edges, key=lambda edge: (edge[2], edge[0], edge[1]))
    if any(not (0 <= u < vertex_count and 0 <= v < vertex_count)
           for u, v, weight in ordered):
        raise ValueError('invalid endpoint')
    dsu = DSU(vertex_count)
    chosen = []
    total = 0
    components = vertex_count
    for u, v, weight in ordered:
        if dsu.union(u, v):
            chosen.append((u, v, weight))
            total += weight
            components -= 1
    return total, chosen, components

Topological sortNo prerequisites left? Release it

Rule: indegree[v] counts incoming edges from unprocessed vertices. The queue contains ready vertices, each enqueued once when its remaining indegree reaches zero.

Python 3.10+ · complete runnable example
from collections import deque


def topological_order(adj):
    indegree = [0] * len(adj)
    for neighbors in adj:
        for v in neighbors:
            indegree[v] += 1
    queue = deque(v for v, degree in enumerate(indegree) if degree == 0)
    result = []
    while queue:
        u = queue.popleft()
        result.append(u)
        for v in adj[u]:
            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)
    if len(result) != len(adj):
        raise ValueError('directed cycle')
    return result

Deeper framework explanation

First specify edge direction, weights, and the complete vertex set, including isolated vertices. Adjacency lists use O(V+E) storage; undirected edges need entries in both directions, and a grid can generate neighbors without storing explicit edges. For reachability, maintain a discovered set and mark when scheduling work to avoid repeated pending entries. A DFS stack follows branches, whereas a BFS FIFO queue expands nondecreasing edge counts: with unit-cost moves, first discovery fixes shortest steps because every shorter predecessor layer was processed earlier. A traversal from one source does not cover disconnected components; iterate unseen roots when that is the question.

Weighted and dependency problems require different promises, not merely different containers. Dijkstra keeps best discovered source-to-vertex costs and expands a nonstale minimum using distance[u] + weight; nonnegative weights make that distance final. Prim grows an undirected tree using the cheapest single edge crossing from included to excluded vertices; the cut property makes this safe even with negative weights, and restarting at unseen roots yields a forest. Kruskal instead sorts edges and joins distinct components. Kahn tracks incoming edges from unprocessed vertices and releases a vertex only when that count becomes zero: its queue represents satisfied prerequisites, not shortest-distance layers. If fewer than V vertices are released, a directed cycle prevents a full ordering.
